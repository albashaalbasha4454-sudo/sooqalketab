# سوق الكتاب

واجهة أولية لمتجر عربي للكتب والمطبوعات مخصص للقراء في سوريا.

## المرحلة الحالية

تتضمن هذه النسخة واجهة رئيسية عربية باتجاه RTL ومتجاوبة مع الهاتف والكمبيوتر، مع بيانات تجريبية للكتب والمطبوعات. تشمل الصفحة الرئيسية البحث التجريبي، تصفية المنتجات، التصنيفات، المنتجات المميزة، الإصدارات الجديدة، السلة التجريبية، والتذييل.

لا تحتوي هذه المرحلة على قاعدة بيانات أو دفع حقيقي أو كتالوج إنتاجي. تم تنظيم المشروع بحيث يمكن إضافة صفحة المنتج والسلة والطلبات ولوحة الإدارة والمخزون لاحقًا.

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run check
npm run build
```

## البنية الأساسية

- `src/App.tsx`: الصفحة الرئيسية والتفاعلات التجريبية.
- `src/index.css`: نظام التصميم والاستجابة ودعم RTL.
- `public/manus-routes.json`: مسارات الصفحات الحالية.
- `TODO.md`: نطاق المرحلة الحالية والخطوات التجارية التالية.
- `netlify.toml`: إعداد البناء والنشر الثابت مستقبلًا.
